Factory Management System is a web-based application designed to help manufacturing companies manage their daily business operations in one centralized platform. The system provides modules for employee management, attendance tracking, inventory management, payroll, expense tracking, and dashboards. It reduces manual record keeping and makes it easier to maintain and access organizational data. The backend is developed using Java and Spring Boot, with Spring Data JPA/Hibernate for database operations and PostgreSQL for data storage. Spring Security and JWT are used for authentication and secure access, while Maven is used for dependency and project management.

In very simple words

This project is like a digital management system for a factory. It allows the company to manage employees, attendance, inventory, salaries, expenses, and other operations from one application instead of maintaining everything separately.

Main features
 Employee Management maintain employee details and workforce information.
 Attendance Management record and manage employee attendance.
 Inventory Management track available materials and inventory.
 Payroll Management manage employee salary and payroll information.
 Expense Management record and monitor company expenses.
 Dashboard provide an overall view of important business information.
 Authentication & Security secure login and access using JWT and Spring Security.
 Database Management store application data using PostgreSQL.
 Docker Support simplify running the application and its required services.
